# Google スプレッドシート同期のセットアップ

このアプリのデータ（レシピ / ジャンル / 予定 / メモ）は Google スプレッドシートに保存されます。
スプレッドシートに `Code.gs` を「ウェブアプリ」として設置し、その URL をアプリに登録します。
Google ログインや API キーの発行は不要です。

## 手順

### 1. スプレッドシートを作る

Google ドライブで新しいスプレッドシートを作成します。名前は何でも構いません。
**シートは自分で作らなくて大丈夫です** — `recipes` / `genres` / `scheduled` / `memos` の
4枚は初回アクセス時に見出し付きで自動生成されます。

### 2. Apps Script を貼り付ける

1. スプレッドシートのメニューから **拡張機能 > Apps Script**
2. 最初から入っている `function myFunction() {}` を全部消す
3. このリポジトリの `gas/Code.gs` の中身を丸ごと貼り付けて保存

### 3. 合言葉（TOKEN）を設定する

ウェブアプリは「全員」に公開する必要があるため、URL を知っている人なら誰でも
アクセスできてしまいます。合言葉を設定して、書き込みを自分たちだけに限定します。

1. Apps Script の左メニューから **プロジェクトの設定**（⚙ アイコン）
2. 一番下の **スクリプト プロパティ** > 「スクリプト プロパティを追加」
3. プロパティ名 `TOKEN`、値に好きな合言葉（例: `wagaya-2026`）を入れて保存

> TOKEN を設定しないうちは合言葉なしで通ります。動作確認には便利ですが、
> 使い始める前に必ず設定してください。

### 4. ウェブアプリとしてデプロイする

1. 右上の **デプロイ > 新しいデプロイ**
2. 歯車アイコンから種類に **ウェブアプリ** を選択
3. 設定:
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
4. **デプロイ** を押す
5. 初回は承認を求められます。「詳細」→「（プロジェクト名）に移動」→「許可」
   （自分のスプレッドシートを自分のスクリプトが触るための承認です）
6. 表示された **ウェブアプリの URL**（`https://script.google.com/macros/s/.../exec`）をコピー

### 5. アプリに登録する

アプリの **⚙ 設定 > 同期設定** に、コピーした URL と手順3の合言葉を入力して「保存」。
自動でリロードされ、同期が始まります。

### 6. 今までのデータを移す

JSONBin に保存していたデータは、アプリの **⚙ 設定 > 移行** タブから移せます。
シートごとに「コピー」を押して、スプレッドシートの同じ名前のシートの **A1 セル**に
貼り付けてください。1行目の見出しごと貼り付けます。タブ区切りなので、
貼るだけで列に分かれます。

貼り付けたらアプリをリロードすると、スプレッドシート側のデータが読み込まれます。

> 移行タブを使わなくても、スプレッドシートが空の状態でアプリを開けば、
> その端末のデータが自動で書き出されます。移行タブは、確実に中身を確認しながら
> 移したいとき・別の端末のデータを移したいときに使ってください。

## 使ううえでの注意

- **スクリプトを編集したら再デプロイが必要です。** 保存しただけでは公開 URL の挙動は
  変わりません。**デプロイ > デプロイを管理 > 編集（鉛筆）> バージョン「新バージョン」> デプロイ**
  としてください。
- **スプレッドシートを直接編集するのは想定していません。** アプリは保存のたびに
  全行を書き換えるため、シート側の編集はアプリの次の保存で消えます。
- **日付は文字列として保存しています。** シートの日付セルが左寄せ（文字列）ではなく
  右寄せ（日付型）になっている場合、表示形式が書き換わっています。
  該当列を選択して **表示形式 > 数字 > 書式なしテキスト** に戻してください。
- 家族で共有するときは、同じ URL と合言葉を各端末の設定に入力すれば同じデータを見られます。
  スプレッドシート自体の共有設定を変える必要はありません（スクリプトが「自分として実行」
  するため）。

## データの構造

| シート | 列 |
|---|---|
| `recipes` | id, name, genreId |
| `genres` | id, name, color |
| `scheduled` | id, recipeId, startDate, endDate, prepDate, mealTime, noPrep |
| `memos` | date, text |

列の順序は `gas/Code.gs` の `SHEETS` と `src/sheets.js` の `SHEET_COLUMNS` の両方に
書かれています。変更するときは両方を揃えてください。
